# Live Demo Script (2–3 minutes)

Preparation (before the defence): open the live URL in a fresh/incognito window → Data & Privacy → *Delete all local data*. Have the backup recording ready. Zoom browser to 110–125 % for the projector.

| Time | Screen | Say (EN) | Action |
|---|---|---|---|
| 0:00 | Home | "Tender AI Fit helps procurement specialists see whether a company's documents meet a tender's requirements — with evidence for every status. It is a rule-based prototype, not an AI system." | Point to hero, 3 steps, disclaimer |
| 0:15 | Home | "The interface works in English and Kazakh." | Click **KZ** → show heading changes → click **EN** back (or continue in KZ) |
| 0:25 | Dashboard | "Our fictional company, Astana Build Solutions, and one demo tender. The next action is suggested." | Click **Try the Demo** |
| 0:35 | Company Profile | "The profile holds licences, certificates, projects, staff and financial statements. Note the ISO 9001 certificate expired on 30 June 2025." | Open **Company Profile**, point to red "Expired on 30.06.2025" |
| 0:50 | Select Tender | "Five requirements from the tender. We start the analysis." | **Select Tender** → **Start Analysis** |
| 1:00 | Analysis | "2 Met, 2 Missing, 1 Unclear. Readiness 40 % — only Met divided by total, not a chance of winning." | Point to summary |
| 1:10 | Analysis | "Boundary case: the ISO certificate file exists, but it is expired, so it does not count. The reason, the evidence and the next step are shown." | Expand **ISO 9001** card |
| 1:25 | Analysis | "Similar projects are Unclear — similarity needs a human. A specialist writes a note and decides." | Expand **Three similar projects**, type note, click **Met** |
| 1:40 | Report | "The report lists Missing items first, keeps the automated 40 % and shows the value after review separately." | **View readiness report** |
| 1:55 | Report | "Export to PDF for the manager." | **Download Report (PDF)** → show print preview → cancel |
| 2:05 | Profile | "If the company renews its certificate, the result updates immediately." | Profile → **Renewed ISO 9001 and audited statement** → Select Tender → Start Analysis → 4 Met, 80 % |
| 2:25 | Tender (optional) | "Wrong file types are rejected with a clear message; uploaded PDFs are never sent anywhere." | Choose a .docx → error |
| 2:35 | Report footer | "Final eligibility decisions remain with a qualified specialist. Limitations: fictional data, five rule types, no PDF reading yet." | Close |

## Kazakh variant (key lines)

- «Tender AI Fit сатып алу мамандарына компания құжаттарының тендер талаптарына сәйкестігін дәлелдермен көрсетеді. Бұл AI емес, ережеге негізделген прототип.»
- «Нәтиже: 2 талап сәйкес келеді, 2 жетіспейді, 1 анық емес. 40% — тек шартты көрсеткіш, жеңіс ықтималдығы емес.»
- «ISO 9001 сертификатының файлы бар, бірақ мерзімі өткен, сондықтан ол есептелмейді.»
- «Түпкілікті шешімді білікті маман қабылдайды.»

## If something fails

- Blank page / network issue → play backup recording.
- Wrong numbers → Company Profile → **Reset demo data** → rerun analysis.
- Language stuck → Data & Privacy → **Delete all local data** → reload.
